## Чего нет и почему

- **Фреймворка HTTP** — Streamable HTTP-транспорт MCP SDK работает поверх `node:http`.
- **ORM** — 8 таблиц, SQL-миграции и подготовленные запросы проще и прозрачнее.
- **Очереди (Redis и т.п.)** — очередь задач в SQLite + in-process планировщик; один хаб по спецификации.
- **Собственного шлюза к провайдерам** — Pi ходит к провайдерам сам (по спецификации «не входит»).

## Риски стека

- TypeScript 7 (нативный компилятор) только вышел: если сломается инструментарий, откат на 6.x не затрагивает код.
- `node:sqlite` помечен в Node как experimental — изолирован за `Storage`, тест миграций гоняется на обоих драйверах.
- Формат RPC Pi может меняться: версия закреплена, адаптер покрыт контрактными тестами на записанных сессиях.
