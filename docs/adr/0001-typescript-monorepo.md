# ADR-0001. TypeScript-монорепо на pnpm

**Контекст.** Хаб, shim, расширение Pi, фейковый воркер и плагины делят типы протокола. Pi, его SDK и MCP SDK написаны на TypeScript.

**Решение.** Один репозиторий, pnpm workspaces, `tsc -b` с project references. Пакеты по границам процессов: `protocol`, `hub`, `shim`, `pi-extension`, `fake-worker`; плагины в `plugins/` (не npm-пакеты, а файлы платформ).

**Последствия.** Изменение протокола видно компилятору во всех процессах сразу. Shim публикуется отдельным маленьким пакетом, чтобы не тянуть зависимости хаба на машину клиента.
