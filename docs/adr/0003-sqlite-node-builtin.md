# ADR-0003. SQLite через `node:sqlite`

**Контекст.** Метаданные в SQLite (WAL), пишет только демон. Нативные модули (`better-sqlite3`) усложняют установку на build-box и обновление Node.

**Решение.** `node:sqlite` (`DatabaseSync`) за интерфейсом `Storage`; SQL-миграции `NNN_*.sql` по `schema_version`. `better-sqlite3` — запасной драйвер с тем же интерфейсом.

**Последствия.** Нулевая нативная сборка. Модуль в Node помечен experimental — тест миграций и запросов гоняется на обоих драйверах, переключение конфигом.
