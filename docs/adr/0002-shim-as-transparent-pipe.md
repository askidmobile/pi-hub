# ADR-0002. Shim — прозрачная труба

**Контекст.** Каждая старшая сессия запускает свой stdio MCP-процесс. Логику, права и список инструментов нужно держать в хабе.

**Варианты.** (A) shim — полноценный MCP-сервер, зовущий хаб по своему RPC; (B) shim пересылает кадры MCP JSON-RPC в хаб, MCP `Server` создаётся в хабе на каждое соединение.

**Решение.** B. Shim отправляет одно сообщение `Hello` (версия протокола, клиент, PID родителя, проект, токен), получает `HelloAck`/`HelloReject` и дальше только копирует байты. Для удалённой работы тот же shim запускается через `ssh build-box pi-hub-shim`; либо клиент ходит в Streamable HTTP хаба через туннель без shim.

**Последствия.** Shim ≈ 100 строк без зависимостей от MCP SDK. `tools/list_changed` и подвал ответов реализуются один раз в хабе. Хаб должен реализовать MCP-транспорт поверх сокета (кастомный `Transport` для SDK).
