# ADR-0007. Идентификация старшей сессии

**Контекст.** MCP не передаёт id сессии клиента. Claude Code и Codex отдают `session_id` только хукам; в окружении MCP-сервера его нет.

**Решение.** Ключ связки — PID процесса агента: shim шлёт `process.ppid`, хук `SessionStart` (`pi-hub hook session-start`) шлёт свой `ppid` и `session_id`. Хаб склеивает их в одну запись `senior_sessions`. Клиент без хуков работает по PID без `client_session_id` (запасной режим).

**Последствия.** Если клиент запускает хуки через промежуточную оболочку, PID родителя нужно поднимать по дереву процессов до процесса агента — `doctor` это проверяет. Возобновлённая сессия клиента (`resume`) получает тот же `session_id`, а новый PID — хаб обновляет `parent_pid`.
