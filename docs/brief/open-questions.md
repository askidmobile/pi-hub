# Открытые вопросы

Статус на 2026-11-26. Детали проверки — [research.md](research.md) и [../research/pi-rpc.md](../research/pi-rpc.md).

| #     | Вопрос                                                         | Статус            | Итог / следующий шаг                                                                                   |
| ----- | -------------------------------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------ |
| OQ-01 | Есть ли в событиях RPC Pi токены и стоимость по каждому ответу | ✅ Закрыт         | Да: `message_update.usage` / `message_end`, включая `cost` и кэш                                       |
| OQ-02 | Как Pi меняет модель и уровень рассуждения через RPC           | ✅ Закрыт         | `set_model`, `set_thinking_level`                                                                      |
| OQ-03 | Система подтверждений Pi                                       | ✅ Закрыт         | Только расширениями (`tool_call` + диалоги Extension UI)                                               |
| OQ-04 | Готовый ACP-адаптер для Pi, польза pi-jev | ✅ Закрыт | ACP-адаптеры есть, но не нужны (RPC напрямую); pi-jev в воркеров не ставим, берём как образец (ADR-0008) |
| OQ-05 | Данные хуков Codex, блокировка завершения хода                 | ✅ Закрыт         | `session_id`, `cwd`, `turn_id`; `decision:"block"` + `reason`                                          |
| OQ-06 | Принимает ли профиль Codex `mcp_servers` и хуки | ✅ Закрыт | Да, проверено на 0.171: файл профиля `~/.codex/pi-hub.config.toml` с `mcp_servers` и хуками, отдельный `CODEX_HOME` не нужен; хуки требуют разового доверия в `/hooks` (ADR-0009) |
| OQ-07 | `tools/list_changed` в Codex и Claude Code | ✅ Закрыт | Claude Code — да; Codex 0.171 — нет (ни в том же, ни в следующем ходе). Список инструментов по клиенту: dynamic для Claude Code, static для Codex (ADR-0010) |
| OQ-08 | Сеть для shim в песочнице Codex | ✅ Закрыт | Проверено на 0.171 (`-s workspace-write`): stdio MCP-процесс подключается к unix-сокету и к HTTP на 127.0.0.1. Путь сокета ≤ 104 символа (лимит macOS), по умолчанию `~/.pi-hub/hub.sock`. Вызовы инструментов pi-hub разрешаются `default_tools_approval_mode = "approve"` в профиле |
| OQ-09 | Jev Router: свой список моделей, ответ, API | ✅ Закрыт | Не нужен: выбор модели — `choice`-вопрос нашего адаптера по таблице ролей (ADR-0008) |
| OQ-10 | Провайдер System One и схема `/v1/systemone` | ✅ Закрыт | Провайдер выбирает пользователь при `pi-hub init` из пресетов; схема `{model, state, questions}` известна (ADR-0008) |
| OQ-11 | Текущие цены и цены кэша DeepSeek, GLM, Kimi, OpenRouter | ✅ Закрыт | Цены есть в каталоге Pi (включая кэш); хаб импортирует их в `prices`, свою таблицу держит только для System One и нулевых цен (BD-016, research/prices.md) |
| OQ-12 | `AGENT.md` не читают ни Claude Code, ни Codex нативно | ✅ Закрыт | Файл переименован в `AGENTS.md` — его читают оба клиента; `CLAUDE.md` не создаётся (BD-012) |
| OQ-13 | Точные таймауты вызова MCP-инструмента у клиентов | ✅ Закрыт | Claude Code: ~28 ч общий, 30 мин простоя для stdio; Codex: 60 с по умолчанию, в профиле 900 с. Потолок `wait`: 1500 с / 870 с / 50 с (ADR-0006) |
| OQ-14 | Этапы разработки: схема из спецификации не сохранилась | ✅ Закрыт | 5 этапов и 4 ворот утверждены автором (брифа §9, BD-019) |
| OQ-15 | Как подключить расширение к `pi --mode rpc` (флаг, пакет) | ✅ Закрыт | `-ne -e <путь>` + свой `PI_CODING_AGENT_DIR`; проверено на Pi 1.6.1: диалог расширения доходит до хаба по RPC и получает ответ (ADR-0011) |
