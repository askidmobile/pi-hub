# Исследование: цены моделей (2026-11-26, OQ-11)

Источник: каталог моделей Pi, `@earendil-works/pi-ai` 1.6.1 (`dist/providers/data/*.json`, сгенерирован к релизу 2026-11-25). Цены в USD за 1M токенов. Pi считает по этому каталогу `usage.cost` каждого ответа — это `cost_source = pi_event`.

## Модели из таблицы ролей спецификации

Через OpenRouter те же модели доступны с другими ценами (динамическая маршрутизация, есть `:batch` и плавающие `~…-latest`), например `openrouter/deepseek/deepseek-v4-flash`: 0.09 / 0.18 / 0.018. Фактическую стоимость OpenRouter возвращает в ответе.

Для сравнения со старшим: `openai/gpt-5.6-sol` — 4 / 20 / 0.4 / 5.

## System One

TypeSafe Jev в каталоге Pi есть как `classifier` с ценой **0** — неверно. По docs.typesafe.ai: $0.042 за 1M входных токенов, выход бесплатно. Цены System One ведёт хаб в своей таблице `prices`.

## Наблюдения

- Каталог покрывает 1696 чат-моделей у ~44 провайдеров; у **134** цена записана нулями — это и бесплатные/локальные модели, и неизвестные цены (например, `zai/glm-5.4`). Ноль нельзя считать «бесплатно».
- Каталог обновляется вместе с версией Pi; версия Pi в хабе закреплена, значит и цены — снимок на момент обновления.
- Встречаются подозрительные значения у OpenRouter (например, `moonshotai/kimi-k3`: вход 0.192, выход 16), поэтому для OpenRouter опираемся на фактическую стоимость из ответа.
